# نظام دعوات الأفراح بـ QR Code

نظام رقمي لإدارة دخول الضيفات في حفلات الأفراح عبر رموز QR فريدة لكل دعوة — مجاني بالكامل بدون سيرفر.

---

## كيف يعمل

### 1. إعداد الدعوات (المنظِّم)
- يفتح صفحة الإدارة ويضيف أسماء الضيفات مع عدد الأشخاص لكل دعوة
- لكل دعوة يُولَّد رمز QR فريد مرتبط بمعرّف خاص في قاعدة البيانات
- يُطبع رمز QR على بطاقة الدعوة مع القالب التصميمي واسم المدعوة
- تُرسل البطاقات للضيفات عبر واتساب أو تُطبع وتُوزَّع

### 2. عند باب القاعة (الاستقبال)
- موظف الاستقبال يمسح رمز QR بكاميرا الجوال
- تظهر النتيجة فوراً:
  - **أخضر ✅** — دعوة صحيحة + عدد الأشخاص
  - **أحمر 🚫** — تم استخدام هذه الدعوة مسبقاً (مع وقت الدخول)
- الرمز يُلغى فور استخدامه — لا يمكن الدخول مرتين

### 3. متابعة الحضور (المنظِّم)
- لوحة حضور تتحدث لحظياً: إجمالي / حضرن / لم يحضرن / نسبة مئوية

---

## الملفات

| الملف | الوظيفة |
|-------|---------|
| `index.html` | صفحة الإدارة — إضافة ضيفات، رفع القالب، توليد الكروت |
| `v.html` | صفحة الفحص — تُفتح عند مسح QR |
| `dashboard.html` | لوحة الحضور اللحظية |
| `firebase-config.example.js` | نموذج إعدادات Firebase (انسخه وسمّه `firebase-config.js`) |

---

## الإعداد

1. أنشئ مشروعاً على [Firebase Console](https://console.firebase.google.com) وفعّل **Realtime Database**
2. انسخ `firebase-config.example.js` وسمّه `firebase-config.js` وضع بياناتك فيه
3. ارفع الملفات على GitHub Pages
4. افتح `index.html` وابدأ بإضافة الضيفات

---

## التقنيات

- **GitHub Pages** — استضافة مجانية ثابتة بدون سيرفر
- **Firebase Realtime Database** — قاعدة بيانات لحظية ومجانية
- **Firebase Transaction** — يمنع دخول نفس الدعوة مرتين حتى عند المسح المتزامن
- **HTML Canvas** — دمج رمز QR مع القالب التصميمي
- **Web Share API** — مشاركة البطاقات وحفظها في معرض الجوال

---

## الميزات

- منع التكرار بـ Firebase Transaction الذري
- دعم العائلات (دعوة واحدة لعدة أشخاص)
- قالب تصميمي قابل للتخصيص مع تحديد موضع QR والاسم
- مزامنة فورية بين الأجهزة
- حماية بكلمة مرور لصفحات الإدارة
- واجهة عربية بالكامل (RTL)
